# CareSim V14 — Full Simulation Edit

- Removed the small Quick Edit modal from the scenario catalog.
- The pencil icon now opens the same full Scenario Builder used after creating a simulation.
- Existing scenario content is preloaded into the builder: basics, patient/media, vitals, actions, assessment Q&A, RAG notes and scoring.
- Instructors can remove/add/edit actions and questions, change patient data, replace media, alter scoring, save and publish/unpublish from the full builder.
- No database migration is required if V12/V13 database migrations are already applied.
